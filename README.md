## 🌟 Ключевые возможности

### 🎯 Умное выделение без переключения инструментов
Вам больше не нужно каждый раз нажимать `V` или выбирать курсор в панели! Находясь в **любом режиме рисования** (Стрелка, Рамка, Карандаш, Текст), просто кликните по любому нарисованному объекту — он мгновенно выделится для перемещения, редактирования или изменения цвета.

### 🏹 Стрелки с интерактивным скруглением (Bézier Curves)
- Острый профессиональный наконечник в стиле CleanShot X и Shottr.
- Потяните за **центральный маркер изгиба**, чтобы плавно изогнуть стрелку в изящную дугу.
- Острие стрелки автоматически и математически точно **проворачивается по касательной кривой Безье**.

### 🔍 Объективное оптическое размытие (Lens / Bokeh Blur)
- Забудьте о грубых пикселях! Инструмент размытия использует мягкий **Gaussian Lens Blur** с эстетичной рамкой матового стекла (*Frosted Glass*), скрывая конфиденциальные данные стильно и дорого.

### ❶ Автонумерованные шаги с 3 масштабами
- Кликайте по важным местам интерфейса для расстановки последовательности `❶`, `❷`, `❸`.
- Мгновенно переключайте размер шагов через универсальные пресеты масштаба (`•`, `●`, `⬤`).

### 🔤 Многострочный текст с автопереносом и масштабированием
- **Автоперенос по правилам русского языка**: движок `NSTextView` с поддержкой русской расстановки переносов (`.byWordWrapping` + `hyphenationFactor`).
- **Задание рамки блока вручную**: протяните рамку нужной ширины при рисовании (drag-to-create) или кликните один раз для создания блока стандартной ширины.
- **Динамическое автозаполнение**: потяните за ручки рамки, чтобы изменить ширину — текст автоматически перераспределится по строкам с динамическим пересчетом высоты плашки.
- **Удобное перемещение и редактирование**: перетаскивайте блок текста в 1 клик, а для редактирования дважды кликните по нему или нажмите `Enter`.

### 🖼 Вставка картинок поверх скриншота (`⌘V`)
- Нажмите **`⌘V`** или кнопку **`📋`** на панели инструментов, чтобы вставить любое изображение из буфера обмена.
- **Всеядный импорт**: файлы из Finder (`⌘C`), картинки из браузеров Chrome/Safari («Скопировать изображение»), системные скриншоты macOS, Telegram, Figma.
- Вставленную картинку можно свободно перемещать, масштабировать за угловые ручки и комбинировать с основным снимком.

### 📐 Свободное рисование в полях и авторасширение холста
- Теперь можно **ставить первую точку стрелки или текста прямо в свободной темной области** снаружи скриншота.
- Если стрелки, пометки или картинки выходят за край снимка — холст автоматически расширяется.
- **Умный экспорт (`calculateExportRect`)**: при копировании (`Enter`) или сохранении файл обрезается точно по границам контента (+16 px отступа для выходящих элементов) без лишних пустых полос!

### ⚡️ Прямая интеграция с LLM / Claude CLI / Termius
- **⚡️ Base64 (`⌘B`)**: Копирует скриншот в буфер в виде base64-строки для мгновенной передачи в веб-чаты и удаленные терминалы через SSH/Termius.
- **📎 CLI Путь (`⇧⌘C`)**: Сохраняет файл в папку `~/Downloads/` с уникальным таймстемпом и копирует абсолютный путь в буфер обмена для использования в скриптах и локальных терминалах.
- **🔤 Vision OCR (`⌘O`)**: Встроенное офлайн-распознавание текста с изображения на базе Apple Vision Framework (русский + английский).

### 🖥 Безупречная работа с multi-monitor и Full-Screen Spaces
- ShotSnap построен на базе системного класса `NSPanel` с флагом `.fullScreenAuxiliary`.
- Окно редактора парит **прямо поверх любого полноэкранного приложения** (браузера, IDE, видеоплеера) на нужном мониторе без дерганья рабочих столов и без смены Spaces.

## 🚀 Быстрый старт

### Требования
- macOS 11.0 (Big Sur) или новее.
- Процессор: Apple Silicon (M1/M2/M3/M4) или Intel x86_64.
- Установленные `Xcode Command Line Tools` (`xcode-select --install`).

### Установка в 1 команду
Склонируйте репозиторий и запустите скрипт установки:

```bash
git clone https://github.com/Arkadius0292/ShotSnap.git
cd ShotSnap
chmod +x install.sh
./install.sh
```

Скрипт автоматически скомпилирует бинарный файл, упакует его в `ShotSnap.app`, подпишет системным сертификатом и установит в папку `/Applications`.

### Первоначальная настройка прав
При первом запуске macOS может запросить стандартные разрешения:
1. **Запись экрана (Screen Recording)** — чтобы делать снимки выбранных областей.
2. **Универсальный доступ (Accessibility)** — для глобального перехвата сочетания клавиш `⌥Z`.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| **`⌥Z`** (*Option + Z*) | **Сделать скриншот** (выделение области курсором) |
| **`⏎`** (*Enter / Return*) | **Скопировать** изображение в буфер обмена и закрыть окно (или открыть выделенный текст) |
| **`⌘V`** (*Cmd + V*) | **Вставить изображение** из буфера обмена на холст |
| **`⌘⏎`** (*Cmd + Return*) | **Подтвердить** и завершить ввод многострочного текста |
| **`⌘B`** (*Cmd + B*) | **Скопировать как Base64** (для Termius / Claude / LLM) |
| **`⇧⌘C`** (*Shift + Cmd + C*) | **Сохранить в Загрузки** и скопировать абсолютный путь |
| **`⌘O`** (*Cmd + O*) | **Распознать текст (OCR)** и скопировать в буфер |
| **`⌘S`** (*Cmd + S*) | **Сохранить файл** через диалоговое окно |
| **`⌘Z`** / **`⇧⌘Z`** | **Отменить** / **Повторить** действие (Undo / Redo) |
| **`⌫`** (*Backspace / Delete*) | **Удалить** выделенный элемент |
| **`⎋`** (*Escape*) | **Закрыть редактор** без сохранения |

### Быстрое переключение инструментов:
- **`A`** — Стрелка
- **`R`** — Рамка
- **`P`** — Карандаш
- **`H`** — Маркер (Хайлайтер)
- **`T`** — Текст
- **`S`** — Нумерованный шаг
- **`B`** — Размытие фона
- **`V`** — Выбор / Перемещение

## 🏗 Архитектура проекта

ShotSnap написан на чистом **Swift / AppKit** без тяжелых сторонних фреймворков:

```
ShotSnap/
├── Info.plist                  # Конфигурация бандла macOS (LSUIElement = true)
├── build.sh                    # Скрипт быстрой компиляции через swiftc
├── install.sh                  # Автоматическая установка в /Applications
├── LICENSE                     # Лицензионное соглашение KULESH.PRO
├── README.md                   # Документация проекта
└── Sources/
    ├── main.swift              # Точка входа в приложение
    ├── AppDelegate.swift       # Жизненный цикл, хоткеи и мониторинг экранов
    ├── HotKeyManager.swift     # Глобальный перехват сочетания клавиш ⌥Z
    ├── CaptureManager.swift    # Захват экрана и работа с координатами мыши
    ├── EditorWindowController.swift # Окно-оверлей NSPanel поверх всех пространств
    ├── CanvasView.swift        # Интерактивный холст для рисования и манипуляций
    ├── ToolbarView.swift       # Верхняя панель инструментов и бэйдж KULESH.PRO
    ├── Annotation.swift        # Геометрия фигур (Безье-стрелки, текст, блюр, картинки, рамки)
    ├── ImageRenderer.swift     # Экспорт, рендеринг, запись в Downloads и Base64
    ├── OCRManager.swift        # Распознавание текста через Apple Vision
    └── PreferencesManager.swift# Сохранение настроек цвета и размера в UserDefaults
```

## 📋 История версий (Changelog)

### [v1.1.0](https://github.com/Arkadius0292/ShotSnap/releases/tag/v1.1.0) — *04 сентября 2026*
- 🔤 **Многострочный текст с автопереносом:**
  - Полноценная поддержка переноса слов по правилам русского языка (`.byWordWrapping` + `hyphenationFactor = 1.0`).
  - Возможность задавать ширину блока при рисовании протягиванием мыши (*drag-to-create*) либо кликом.
  - Динамическое автозаполнение при изменении ширины за ручки рамки с пересчетом высоты плашки.
  - Устранено оптическое задвоение шрифта во время инлайн-редактирования.
  - Плавное перемещение блока текста в 1 клик и открытие редактирования по двойному клику или `Enter`.
  - Автоматическое переключение инструмента в режим «Выбор» после подтверждения ввода текста.
- 📐 **Полноразмерный холст и рисование в полях:**
  - `CanvasView` теперь занимает 100% пространства окна: первую точку стрелки или текста можно ставить сразу в темном поле снаружи скриншота с первого клика.
  - Интеллектуальный расчет экспортной области (`calculateExportRect`): снимок обрезается точно по контенту без лишних пустых полос, оставляя комфортный отступ 16 px только для выходящих наружу элементов.
- 🖼 **Вставка изображений из буфера обмена (`⌘V`):**
  - Поддержка вставки изображений поверх скриншота с возможностью масштабирования и свободного перемещения (`ImageAnnotation`).
  - Всеядный парсер буфера обмена: файлы из Finder (`⌘C`), веб-картинки из Safari/Chrome, Telegram, снимки экрана macOS.
  - Новая кнопка **`📋` (Вставить)** на панели инструментов рядом с отменой действия.
- 🎯 **Строгие зоны клика для выделения:**
  - Сужен допуск клика до 4–5 px от тела линии (стрелок, рамок, маркера), что исключает случайный захват соседних объектов при плотном рисовании.

### [v1.0.0](https://github.com/Arkadius0292/ShotSnap/releases/tag/v1.0.0) — *19 августа 2026*
- Первый публичный релиз:
  - Стрелки на базе квадратичных кривых Безье со скруглением и поворотом острия.
  - Объективный Lens / Bokeh размытие фона.
  - Автонумерованные шаги с тремя пресетами толщины и масштаба.
  - Экспорт в Base64 для передачи через Termius/SSH.
  - Кнопка CLI Путь с сохранением в `~/Downloads/`.
  - Офлайн-распознавание текста через Apple Vision OCR.
  - Парящая `NSPanel` с поддержкой всех мониторов и Full-Screen Spaces.
  - Интерактивный бэйдж KULESH.PRO со ссылкой на сайт автора.
